# Museau & Plume — Site e-commerce premium chiens & chats

Prototype de boutique e-commerce orientée conversion douce pour des accessoires utiles (pas un catalogue massif), avec un positionnement bien-être animal et une structure par situations de vie.

## Pages créées
- `index.html` : homepage émotionnelle + sélection de 5 essentiels
- `categories.html` : catégories par situations
- `product-voyage.html` : page produit complète (voyage)
- `product-stimulation.html` : page produit complète (stimulation)
- `product-repos.html` : page produit complète (repos)
- `about.html`, `faq.html`, `contact.html`, `returns.html`

## Lancer en local
```bash
python -m http.server 8000
```
Puis ouvrir `http://localhost:8000`.
